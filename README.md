# مستودع إيقاف المنصة نهائياً (404 Not Found)

هذا المستودع مستقل تماماً ومخصص لإيقاف الموقع نهائياً بعرض شاشة **404 خطأ**.

## طريقة الاستخدام:
1. أنشئ مستودعاً جديداً فارغاً على حسابك في GitHub (مثلاً باسم: `medhall-stopped`).
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى المستودع الجديد.
3. ادخل على لوحة تحكم **Cloudflare Pages** وافتح مشروع الموقع.
4. اذهب إلى: **Settings** > **Builds & deployments**.
5. قم بتغيير المستودع المرتبط (**Connect a different repository**) واختر المستودع الجديد.
6. اضغط **Save and Deploy**.

### النتيجة:
- الموقع سيتوقف تماماً عن العمل.
- أي زائر يدخل على أي رابط أو صفحة رئيسية سيظهر له كود الخطأ: **404 Not Found**.
- لا يوجد أي كود أو أدوات أو ذكاء اصطناعي أو اتصالات قديمة نهائياً.
